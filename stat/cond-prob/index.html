Same chances, different stories

P(A) = 0.50 and P(B) = 0.30 in every story. Without calculating, which story has the biggest P(A ∪ B), and which the smallest?

Same chances, different OR

StoryA, BP(A)P(B)OverlapP(A ∪ B) = P(A) + P(B) − Overlap
1cash, card0.500.3000.50 + 0.30 − 0 = 0.80
2glasses, iced coffee0.500.300.150.50 + 0.30 − 0.15 = 0.65
3phone, phone cover0.500.300.250.50 + 0.30 − 0.25 = 0.55

Same P(A), same P(B), three different ORs. Why are the answers different? The overlap decides. So we must know how the two events relate.

What if the overlap is not given?

  • AND: toss a coin twice. Find P(Heads first ∩ Tails second). There is no table and no “both” count.
  • OR: P(A) = 0.50 and P(B) = 0.30. Find P(A ∪ B). The overlap is not given.

The Venn diagram and counting cannot answer these yet. We need to know how the events relate.

Next: sort the stories into types, and learn a way to know the overlap for each.

Sorting the stories

Ask two questions about each story.

StoryCan both happen?Does one change the chance of the other?Type
1Nonot neededMutually exclusive
2YesNoIndependent
3YesYesDependent

Check: independent means overlap = P(A) × P(B) = 0.15. Story 2 matches. Story 3 has 0.25, so it does not.

Mutually exclusive

Two events that cannot happen at the same time. The circles do not overlap.

AND is impossible: P(A ∩ B) = 0

So OR is just adding. There is no overlap to subtract.

P(A ∪ B) = P(A) + P(B)

Question 5 of 15

A parcel’s current status. A = Delivered. B = Cancelled.

Which one? Mutually exclusive · Independent · Dependent

Hint: Can a parcel have both statuses right now?

Answer: Mutually exclusive

No. A parcel has one current status. If one is true, the other cannot be.

Independent

They can happen together. Knowing one happened tells you nothing about the other.

The test: does one change the chance of the other? No.

Independent events do overlap. The circles must cross.

Independent: AND means multiply

Two coin tosses: Heads first AND Tails second.

P(A ∩ B) = P(A) × P(B)

0.5 × 0.5 = 0.25

OR still works the same way: add, then subtract the overlap.

Do not learn “AND = multiply”. Learn “AND + independent = multiply”.

What changes when events are independent?

Any eventsIf the events are independent
ANDcount, or P(A) + P(B) − P(A ∪ B)also P(A) × P(B)

Independent changes AND only. OR stays the same.

Independent: both methods agree

Example 1. A shop has 500 customers. 200 buy online, 150 use a coupon, and 60 do both. Find P(online ∩ coupon) two ways, then P(online ∪ coupon).

  1. Events. Event A: buys online. Event B: uses a coupon.
  2. Count. P(A ∩ B) = 60 ÷ 500 = 0.12
  3. Multiply. P(A) = 200 ÷ 500 = 0.40 and P(B) = 150 ÷ 500 = 0.30. So 0.40 × 0.30 = 0.12
  4. Compare. Both give 0.12, so the events are independent.
  5. OR. P(A ∪ B) = 0.40 + 0.30 − 0.12 = 0.58

Independent: both methods agree

Example 2. A coin and a die are thrown together 600 times. Heads came up 300 times, a 5 or 6 came up 200 times, and both happened 100 times. Find P(Heads ∩ 5 or 6) two ways.

  1. Events. Event A: Heads. Event B: the die shows 5 or 6.
  2. Count. P(A ∩ B) = 100 ÷ 600 = 0.1667
  3. Multiply. P(A) = 300 ÷ 600 = 0.50 and P(B) = 200 ÷ 600 = 0.3333. So 0.50 × 0.3333 = 0.1667
  4. Compare. Same answer, so the events are independent.

Another method: AND from the OR

Example 3. In the same shop, P(online) = 0.40 and P(coupon) = 0.30. You are told that 0.58 of customers buy online OR use a coupon. Find P(online ∩ coupon).

  1. Events. Event A: buys online. Event B: uses a coupon.
  2. Rearrange the OR rule. P(A ∩ B) = P(A) + P(B) − P(A ∪ B)
  3. Substitute. 0.40 + 0.30 − 0.58 = 0.12
  4. Check. Same 0.12 as counting and multiplying. This method works for any events, independent or not.

Sometimes the methods do not agree

Example 4. 400 students: 200 attend, 160 pass, 140 do both. Find P(attend ∩ pass) by counting and by multiplying.

  1. Count. 140 ÷ 400 = 0.35
  2. Multiply. 0.50 × 0.40 = 0.20
  3. Compare. 0.20 is not 0.35, so the events are dependent. Trust the count.

Example 5. 250 orders: 100 have a burger, 50 have fries, 40 have both. Find P(burger ∩ fries) by counting and by multiplying.

  1. Count. 40 ÷ 250 = 0.16
  2. Multiply. 0.40 × 0.20 = 0.08
  3. Compare. 0.08 is not 0.16, so the events are dependent. Trust the count.

Your turn

For each problem: find P(A ∩ B) by counting, find it by multiplying, and compare. What does it tell you about the two events?

Problem 1. 300 customers: 150 buy tea, 90 buy biscuits, 45 buy both.

Count: 45 ÷ 300 = 0.15. Multiply: 0.50 × 0.30 = 0.15. They agree, so the events are independent.

Problem 2. 200 employees: 80 work the night shift, 60 get a transport allowance, 50 get both.

Count: 50 ÷ 200 = 0.25. Multiply: 0.40 × 0.30 = 0.12. They disagree, so the events are dependent. Trust the count: 0.25.

Problem 3. 400 students: 200 play sports, 160 have a part-time job, 40 do both.

Count: 40 ÷ 400 = 0.10. Multiply: 0.50 × 0.40 = 0.20. They disagree, so the events are dependent. Trust the count: 0.10.

No counts given: multiply

Example 6. A die is rolled twice. The rolls are independent. Find P(6 on roll 1 ∩ 6 on roll 2).

  1. Events. Event A: a 6 on roll 1. Event B: a 6 on roll 2.
  2. Method. No counts are given and the events are independent, so multiply.
  3. Compute. 1/6 × 1/6 = 1/36 ≈ 0.0278

Example 7. Two separate parcels arrive on time with chances 0.90 and 0.85. The parcels are independent. Find the chance that both arrive on time.

  1. Events. Event A: parcel 1 on time. Event B: parcel 2 on time.
  2. Method. No counts are given and the events are independent, so multiply.
  3. Compute. 0.90 × 0.85 = 0.765

Independent: examples

  • You visit Bangkok this year. The PM visits Bangkok this year. Separate trips, separate dates.
  • A customer wears glasses. The customer orders iced coffee.
  • Two coin tosses: Heads first, Tails second.
    P(A ∩ B) = 0.5 × 0.5 = 0.25
  • Two separate prize draws. You win the first with 0.30, the second with 0.20.
    AND: 0.30 × 0.20 = 0.06. OR: 0.30 + 0.20 − 0.06 = 0.44
  • Two independent checkpoints, passed with 0.95 and 0.90.
    Pass both: 0.95 × 0.90 = 0.855

Question 10 of 15

A bag has 5 red and 5 blue marbles. Draw one, put it back, shake, draw again. A = first is red. B = second is red.

Which one? Mutually exclusive · Independent · Dependent

Hint: Is the bag the same for the second draw?

Answer: Independent

Yes. Putting it back restores the bag, so the first draw cannot change the second.

Dependent

They can happen together, but one changes the chance of the other. Like a domino.

For AND, do not just multiply the two single chances. Use the overlap count in the data.

Dependent: examples

  • 100 days. 30 rainy days, 31 days with many umbrellas sold, 24 days with both.
    Multiplying gives 0.30 × 0.31 = 0.093. The data says 24 ÷ 100 = 0.24. Multiplying fails here.
  • A customer buys a phone. The same customer buys a phone cover.
  • Two cards drawn, the first kept out: an Ace first, an Ace second. After one Ace is gone, only 3 of the 51 cards left are Aces.

Question 15 of 15

Roll a die once. A = you roll a 6. B = you roll more than 4.

Which one? Mutually exclusive · Independent · Dependent

Hint: Can both happen? If you roll a 6, is “more than 4” certain?

Answer: Dependent

Both can happen (a 6 is both). Knowing A happened makes B certain, so one changes the other.

Mutually exclusive is not independent

Roll a die once. A = odd (1, 3, 5). B = even (2, 4, 6).

If the roll is odd, even is impossible. If the roll is even, odd is impossible. Each event wipes out the other.

One event changes the chance of the other, so they are dependent.

If two events cannot happen together, they are never independent.
