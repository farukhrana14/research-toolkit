Test 1: Name the type

15 questions. No calculation is needed. For each pair of events, ask: can both happen together? If yes, does one change the chance of the other?

Answer all 15, then press Check my answers.

Question 1

Two dice are rolled once. Event A: the first die shows a 6. Event B: the sum of the two dice is 12. What type of events are A and B?

Question 2

Six students are waiting to present: 3 from Section 1 and 3 from Section 2. The teacher picks one at random to go first, then picks a second, different student at random. Event A: the first student is from Section 1. Event B: the second student is from Section 1. What type of events are A and B?

Question 3

A traffic light shows only one colour at a time. At a given moment, Event A: the light is red. Event B: the light is green. What type of events are A and B?

Question 4

On a summer day in a beach town, Event A: ice-cream sales are high. Event B: there are more swimming accidents than usual. Eating ice cream does not cause swimming accidents. What type of events are A and B?

Question 5

Rina buys a ticket in one lottery draw in Dhaka. Tuhin buys a ticket in a separate lottery draw in Sylhet. Event A: Rina wins her draw. Event B: Tuhin wins his draw. What type of events are A and B?

Question 6

A spinner is spun, and then a fair die is rolled. Event A: the spinner lands on blue. Event B: the die shows a 4. What type of events are A and B?

Question 7

Rafi and Sara each buy one ticket for a raffle that has only one prize. Event A: Rafi wins the prize. Event B: Sara wins the prize. What type of events are A and B?

Question 8

A student is picked at random from the university. Event A: the student’s ID number ends in an even digit. Event B: the student was born between January and June. What type of events are A and B?

Question 9

Sadia draws a card from a standard deck, puts it back, shuffles the deck, and draws a second card. Event A: the first card is a Spade. Event B: the second card is a Spade. What type of events are A and B?

Question 10

On a given morning, Event A: it is raining heavily in the city. Event B: traffic on the main road is slow. What type of events are A and B?

Question 11

Two dice are rolled once, and the numbers on the two dice are added. Event A: the sum is 12. Event B: the sum is 2. What type of events are A and B?

Question 12

A passenger is given exactly one seat on a flight. Event A: the passenger is given seat 12A. Event B: the passenger is given seat 14C. What type of events are A and B?

Question 13

Tariq’s phone switches on power-saving mode by itself when its battery falls below 20 percent. It can also be switched on by hand. Event A: the battery is below 20 percent. Event B: the phone is in power-saving mode. What type of events are A and B?

Question 14

A fair coin is tossed six times. Event A: the first five tosses are all Tails. Event B: the sixth toss is Heads. What type of events are A and B?

Question 15

A fair die is rolled once. Event A: the number shown is greater than 4. Event B: the number shown is less than 3. What type of events are A and B?
